# Ya programist gpt — фізика КПІ, версія 1.7.0

Збірка для наявного GitHub Pages. Розпакуйте її в корінь репозиторію. Розділ «Курс КПІ» містить авторські навчальні пояснення за програмою.


Навчальна платформа з фізики українською. Для GitHub Pages завантажити весь вміст архіву в корінь наявного репозиторію (заміна файлів).

- 21.09: динаміка матеріальної точки з двох записів; імпульсна форма другого закону та закони сил.

Таймкоди орієнтовні, у нових розділах зазначено частину відеозапису. Усну теорію переказано за автоматичною розшифровкою, формули та рисунки вибірково звірено з кадрами. Це не дослівний стенографічний запис. Додаткові задачі й питання створені для навчання, не є офіційними білетами. Вихідні відео, імена учасників, фото і аудіо не публікуються. Прогрес зберігається в браузері, старі ідентифікатори лекцій та порядок попередніх тестів збережено.

## 1.4.3 — MP3-аудіоогляди
- Новий HTML5-плеєр: MP3, пауза, перемотування, темп, розділи, завантаження, автоматичний перехід.
- MP3 не входять до архіву: для їх створення запустити Generate_audio_windows.bat у корені сайту. Потрібні Python 3.12 та інтернет. Генератор використовує edge-tts і передає Microsoft лише авторські навчальні сценарії з tools/podcasts.json, не записи викладача. Після успішної генерації опублікувати файли через GitHub Desktop. Повторний запуск пропускає вже створені незмінені аудіо.
- Резервне озвучення через браузер залишено. За відсутності MP3 або голосу показується повідомлення.

## 1.4.4
- Один суцільний MP3 на кожне з п’яти занять. Нові сценарії охоплюють усі основні підтемі, усні пояснення, приклади та питання до іспиту. Це навчальні огляди, не повна стенограма.
- Запустіть Generate_audio_windows.bat після розпакування в корінь репозиторію; нові файли `audio/*-full-v144.mp3` потрібно опублікувати. Попередні частини MP3 можуть залишитися, але не використовуються.
- Стрілки над векторами у вебінтерфейсі малюються CSS без комбінованого символу; SVG-формули збережено. PDF залишено з попередньої версії.
- Виправлено шлях до віртуального середовища та додано перевірку місця запуску BAT.
