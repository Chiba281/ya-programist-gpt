# Ya programist gpt — фізика

Навчальний сайт українською мовою. Усі матеріали першої лекції зберігаються у `lectures.js`; сайт не потребує сервера, API-ключів або встановлення бібліотек. Прогрес зберігається локально в браузері, не синхронізується між пристроями. Сайт не генерує матеріали самостійно.

## Запуск
Розпакуй ZIP. Відкрий `index.html` у браузері. Не запускай файл прямо з архіву. Для локальної перевірки через HTTP за наявності Python: відкрий термінал у папці сайту, виконай `python -m http.server 8000 --bind 127.0.0.1`, відкрий http://127.0.0.1:8000. Локальний запуск не є публікацією.

## Публікація
1. Увійди у свій GitHub (або створи обліковий запис, якщо можеш користуватися ним за його умовами).
2. Створи публічний репозиторій `ya-programist-gpt`.
3. Завантаж в корінь репозиторію вміст цього архіву (не сам ZIP), зберігши папку `pdf`. Підтвердь зміни (Commit changes).
4. Settings → Pages → Build and deployment → Source: Deploy from a branch → main → /(root) → Save.
5. У Settings → Pages після успішної публікації з'явиться URL. Типовий вигляд: `https://USERNAME.github.io/ya-programist-gpt/`. USERNAME — ім'я власника репозиторію; це не готове посилання.
6. Відкрий URL на телефоні. Кнопка «Поділитися» на сторінці лекції копіює або передає адресу поточного розділу.

Офіційна довідка: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Додавання лекцій
Надішли в чат текст `transcript.txt` (якщо є), кадри JPG та CSV або стиснене відео. Для доповнення цього сайту також надай актуальний `lectures.js` або доступ до репозиторію. Нові лекції додаються в масив `window.LECTURES` з унікальним `id`; PDF зберігається в `pdf/`. Не змінюй ідентифікатори та порядок старих тестових питань без міграції — до них прив'язаний локальний прогрес. Оновлені `lectures.js` і PDF треба опублікувати у тому ж репозиторії. За наявності підтримуваного доступу ChatGPT до репозиторію можна перевірити можливість прямої публікації; інакше завантажити оновлення вручну.

## Обмеження
Публічний сайт доступний будь-кому, може індексуватися пошуковими системами. Не завантажуй особисті дані, записи викладачів чи інші матеріали без дозволу. У першій лекції є оригінальний конспект, створений за вибірково переглянутими слайдами, та додаткові навчальні завдання; відео й аудіо не публікуються. Немає авторизації, синхронізації прогресу або вбудованого ШІ. PDF готовий для завантаження. У середовищі розробки виконано перевірку синтаксису JS і структури даних; перевірка в реальному браузері заблокована політикою середовища, тому перед поширенням перевір основні вкладки.
