Задача 1.2

Рівновага між зарядами

Два додатні заряди q і 4q розділяє 60 см. Де розмістити пробний заряд і який його знак забезпечить стійкість уздовж прямої?

Покрокове розв’язання
  1. Між зарядами поля спрямовані назустріч. Позначимо через x відстань від меншого заряду. Відстань до більшого дорівнює 60 − x (см).
  2. Прирівняємо модулі полів. Із kq/x² = 4kq/(60 − x)² маємо 60 − x = 2x, тому x = 20 см.
  3. Якщо змістити пробний заряд до меншого, поле меншого посилиться, а більшого ослабне. Сумарне поле штовхатиме додатний заряд назад. Отже, місце рівноваги однакове для обох знаків, а вздовж цієї прямої рівновага стійка для додатного заряду.
Задача 1.4

Сила в діелектрику

У повітрі відстань між зарядами становить 20 см. Якою має бути відстань у рідині з відносною проникністю 5, щоб сила збереглася?

Покрокове розв’язання
  1. Для точкових зарядів у однорідному діелектрику модуль сили дорівнює k|q₁q₂|/(εᵣr²). Для повітря беремо εᵣ ≈ 1.
  2. Прирівнюємо сили та скорочуємо однакові множники. Одержуємо r₁² = 5r₂², звідки r₂ = 20/√5 ≈ 8,94 см.
  3. Перевірка: середовище послаблює взаємодію у 5 разів. Зменшення відстані у √5 разів компенсує це послаблення.
Задача 3.1

Кількість витків котушки

Коротка котушка радіусом 16 см зі струмом 5 А створює в центрі поле 1 мТл. Скільки в ній витків?

Покрокове розв’язання
  1. У центрі одного круглого витка B₁ = μ₀I/(2R). Для короткої котушки поля N близько розташованих витків приблизно однакові й додаються.
  2. Із B = Nμ₀I/(2R) отримуємо N = 2RB/(μ₀I). У СІ радіус становить 0,16 м, індукція — 0,001 Тл.
  3. Підставляємо μ₀ ≈ 4π·10⁻⁷ Тл·м/А. Маємо N ≈ 50,9, тобто приблизно 51 виток.
Задача 1.15

Де поле кільця найсильніше?

Кільце радіусом 6 см має рівномірний заряд 20 нКл. Як змінюється поле вздовж осі кільця?

Покрокове розв’язання
  1. Поперечні складові полів протилежних елементів взаємно компенсуються. Відстань від кожного елемента кільця до точки на осі дорівнює √(R² + x²).
  2. Помножимо поле елемента k dq/(R² + x²) на косинус кута з віссю x/√(R² + x²). Після додавання внесків усього кільця одержимо Eₓ = kqx/(R² + x²)³ᐟ².
  3. Для x ≥ 0 знак похідної визначає R² − 2x². Максимум при x = R/√2 ≈ 4,24 см. Підстановка у формулу дає E ≈ 19,2 кВ/м. На протилежному боці кільця модуль має такий самий максимум.
  4. У центрі поле дорівнює нулю за симетрією. Далеко від кільця (x ≫ R) отримуємо E ≈ kq/x², як для точкового заряду.
Задача 1.5

Заряджені кульки в діелектрику

Дві однакові кульки на нитках занурили у рідину з густиною вдвічі меншою за густину кульок. Кут між нитками залишився таким самим. Знайди відносну діелектричну проникність рідини.

Покрокове розв’язання
  1. Познач кут між ниткою й вертикаллю через β. До занурення вертикальна складова натягу врівноважує mg, горизонтальна — електричну силу F. Ділення рівнянь дає tg β = F/(mg).
  2. У рідині на кульку діє виштовхувальна сила Fₐ = ρрідини Vg = mg/2. Тому вертикальна складова натягу зменшується до mg/2.
  3. Відстань між кульками та їхні заряди ті самі. Електрична сила у рідині дорівнює F/εᵣ. Оскільки кут не змінився, маємо F/(mg) = (F/εᵣ)/(mg/2). Скорочення дає εᵣ = 2.
Задача 1.9

Сила взаємодії в координатах

Заряди +50 мкКл і +10 мкКл розташовані в точках (2, 3) м та (8, −5) м. Знайди силу, що діє на другий заряд.

Покрокове розв’язання
  1. Вектор від першого заряду до другого має компоненти (8 − 2, −5 − 3) = (6, −8) м. Відстань r = √(6² + 8²) = 10 м. Одиничний вектор напряму дорівнює (0,6; −0,8).
  2. Підставляємо значення у СІ. F = 9·10⁹ · (50·10⁻⁶) · (10·10⁻⁶) / 10² = 0,045 Н. Обидва заряди додатні, отже другий відштовхується від першого.
  3. Множення модуля на одиничний вектор дає Fₓ = +0,027 Н, Fᵧ = −0,036 Н. Перевірка: √(0,027² + 0,036²) = 0,045 Н.
