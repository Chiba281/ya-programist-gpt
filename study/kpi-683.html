Лекція 3.13. Рівняння Максвелла

Змінне магнітне поле створює вихрове електричне поле. Магнітне поле може виникати через струм провідності та через зміну електричного поля. Разом з двома законами для потоків ці співвідношення утворюють рівняння Максвелла.

Для самоперевірки

Що підтримує магнітне поле між обкладками ідеального конденсатора під час заряджання?

Змінний електричний потік відповідає струму зміщення. Перенесення вільних зарядів крізь діелектричний проміжок для цього не потрібне.
