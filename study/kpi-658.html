Лекція 2.1. Основні положення МКТ

Тиск виникає через передавання імпульсу стінці під час ударів молекул. Для рівноважного ідеального газу p = nm₀⟨v²⟩/3 = nkT. Тут n = N/V, а m₀ — маса однієї молекули.

Для самоперевірки

При незмінній температурі концентрація зростає вдвічі. Як зміниться тиск?

Зросте вдвічі. Середня кінетична енергія поступального руху окремої молекули залишиться сталою.
