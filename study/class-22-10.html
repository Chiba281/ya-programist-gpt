22.10 · Газові закони та парціальний тиск

Для суміші ідеальних газів кожен компонент заповнює весь об’єм. Запиши pᵢ = νᵢRT/V. Підсумовування дає закон Дальтона p = Σpᵢ.

Лекція 2.1. Основні положення МКТ

Тиск виникає через передавання імпульсу стінці під час ударів молекул. Для рівноважного ідеального газу p = nm₀⟨v²⟩/3 = nkT. Тут n = N/V, а m₀ — маса однієї молекули.

При незмінній температурі концентрація зростає вдвічі. Як зміниться тиск?

Зросте вдвічі. Середня кінетична енергія поступального руху окремої молекули залишиться сталою.

Лекція 2.2. Властивості газів

Рівняння pV = νRT описує ідеальний газ. Для реального газу модель Ван дер Ваальса враховує притягання молекул і недоступний їм об’єм. Для одного моля (p + a/Vₘ²)(Vₘ − b) = RT.

Коли поправки до моделі ідеального газу зменшуються?

При великих молярних об’ємах величини b/Vₘ та a/Vₘ² малі. Придатність наближення залежить також від температури.
