05.11 · Перший закон у задачах

Почни з таблиці станів p, V, T. На кожній ділянці окремо обчисли ΔU та роботу. Сума робіт за замкнений цикл дорівнює підписаній площі всередині циклу.

Лекція 2.4. Перше начало термодинаміки

За домовленістю A > 0 означає роботу газу. Перший закон має вигляд Q = ΔU + A. У ізохорному процесі A = 0, у адіабатичному Q = 0. Для ідеального газу внутрішня енергія залежить від температури.

Газ отримав 120 Дж теплоти й виконав 45 Дж роботи. Як змінилася U?

ΔU = 120 − 45 = 75 Дж.

Лекція 2.5. Теплоємність. Політропні процеси

Молярна теплоємність показує кількість теплоти на зміну температури одного моля на один кельвін за певних умов. Для ідеального газу Cₚ − Cᵥ = R. У політропі pVⁿ = const значення n визначає тип процесу.

Чому Cₚ більша за Cᵥ?

При ізобарному нагріванні ідеальний газ розширюється, тож частина підведеної енергії витрачається на роботу.
